### 실제 작업일보 머리 이름 점검 (2026-10-27 저녁, 기획서 11.8)

수강생의 실제 작업일보로는 그래도 ② 소재 탭이 바뀌어 보인다는 전달 — 실제 파일 없이 머리 이름을 바꿔 가며 넣어 보니 **한 줄 머리에서도 같은 증상**이 났습니다. 「소재」가 소재규격 별칭이라 앞 칸이 먼저 차지하고, 진짜 「규격」 칸은 「한 번 더 보입니다」로 버려졌습니다.

| 머리(소재 칸) | 전 | 지금 |
|---|---|---|
| `소재 \| 규격` · `소재 \| 소재규격` · `규격 \| 소재` | 메이커 없음, 규격 = 「소재」 칸(회사 이름), 「규격」 버림 | 메이커 = 「소재」, 규격 = 「규격」 |
| `소재명 \| 소재 사양` | 메이커 없음 | 메이커 = 소재명, 규격 = 소재 사양 |
| `원소재 \| 제조사` · `자재 \| 공급업체` · `공급사 \| 재질` | 규격 없음 / 둘 다 없음 | 회사 쪽 = 메이커, 남은 소재 칸 = 규격 |
| `Material \| Spec` · `Supplier \| Material` · `Maker \| Grade` | 메이커 · 규격 일부 없음 | 제자리 |
| `재질 \| 소재`(둘 다 애매) | 「재질」 = 규격, 「소재」 버림 | 아래 값 모양으로(회사 이름 = 메이커, STS304 0.8t = 규격) |
| `메이커 \| 규격` 인데 값이 뒤바뀜 | 그대로 뒤바뀜 | 머리대로 두고 「소재 메이커 칸에 규격처럼 보이는 값이 있습니다 — 열 연결을 확인해 주세요」 + 「두 칸 바꾸기」 |

- 쌓인 자료: 열 읽기 판 3 — 판 2(오후)까지로 가져온 자료에도 「다시 가져오기」 알림. ② 화면도 쌓인 행의 값 모양을 보고 뒤바뀌었으면 「두 칸 바꾸기」.
