# data10-16 · 원/부자재 미결 방지 사전 관리

입출고 수불 엑셀과 생산계획으로 자재(강종·규격)별 대당 출고 요율을 내 차 3개월 예상 출고·월별 기초재고·부족량을 굴리고, MOQ·리드타임·안전재고를 반영해 발주 마감과 권장 발주량을 우선순위 색(빨강·주황·노랑·초록)으로 구분한 발주 리스트, 장기·불용 재고 지표, AI 프롬프트(사실만·이름 가림)와 보고서 초안을 만드는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 이성헌 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-10-27) — https://aebonlee.github.io/data10-16/ |
| 다음 개발 | 2단계 — 실제 수불·생산계획으로 열 연결·기준값 확정, 발주서 양식 출력, lot 절단 계획·대체 규격 반영 |

> 과제는 패들릿으로 접수했습니다. 실제 수불 엑셀은 아직 받지 않았고(기획서 10장 ①), 샘플은 제출 글의 항목대로 새로 만든 **가상 값**입니다(가짜 자재코드 RM-1xx, 공급사A~D). 소속 회사명은 리포에 두지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-16/**

처음 열면 「데이터 가져오기」 화면입니다. **「샘플로 시작」** 을 누르면 가상 수불(자재 20종 × 직전 24개월)·생산대수(실적 + 차 3개월 계획)·발주 기준이 들어가고 ② 발주 리스트로 넘어갑니다.
샘플에는 일부러 심은 것이 있습니다 — lot 절단으로 출고가 몰리는 RM-102, 리드타임이 긴 RM-104(둘 다 빨강), 최근 대당 출고가 늘어난 RM-110, MOQ 가 사용량의 9배인 RM-112, 14개월 무출고 RM-113. RM-103·107·109 는 재고가 넉넉한 대조군입니다.
실제로 쓸 때는 기준월(당월)의 수불 엑셀을 넣어 주세요. 수불 현황·생산대수·발주 기준이 한 통합문서의 시트로 나뉘어 있어도, 파일로 나뉘어 있어도 됩니다. 열 이름이 조금 달라도 찾고, 못 찾은 열은 화면에서 골라 연결합니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).

| 화면 | 하는 일 |
|---|---|
| 데이터 가져오기 | 수불 엑셀 여러 개 · 시트 종류 자동 가름(수불 현황 · 생산대수 · 발주 기준, 바꿀 수 있음) · 제목 줄 아래 머리행 자동 인식 · 월 열(「2026-09」「25.10 출고」「M-1」「직전 3개월」, 윗줄 「출고 실적」「입고 실적」 묶음) · 기준월 찾기·고치기 · 열 연결 확인/수정 · 「합계」 줄 제외 · 같은 자재 두 줄은 합침 |
| ① 예상 출고 | 월별 생산대수(실적·차 3개월 계획) · 자재별 분기·반기·년간 평균 출고 · 대당 요율(분기·반기·년간 단추) · 「분기/년간」 요율 변화 · 월별 출고 변동(lot 절단 의심) · 차 3개월 예상 출고 |
| ② 발주 리스트 | 우선순위 색(빨강 긴급 · 주황 이번 달 발주 · 노랑 발주 예정 · 초록 충분) · 월말 재고 3개월(결품·안전재고 아래 칸 표시) · 발주 마감 · 필요량 · MOQ·발주단위 반영 권장 발주량 · 강종별 부족량 · 월별 굴리기 자세히 · 엑셀(5개 시트) |
| ③ 장기·불용 지표 | 재고 개월수(현재고 ÷ 년간 평균 출고) · 마지막 출고 · 출고 감소 · MOQ 과다 · 재고 금액(단가가 있으면) |
| ④ AI 프롬프트 | 계산된 사실만 담은 프롬프트 — **공급사·자재코드는 「공급사1」「자재2」 같은 별칭으로 가림(기본)**, 대응표는 이 PC 에만, AI 답은 원래 이름으로 되돌림(복사·붙여 넣기, 선택: 설정한 AI 서버로 자동 보내기) |
| ⑤ 보고서 | 총괄·계산 기준·발주 리스트·강종별 부족량·장기·불용·AI 의견 — 인쇄/PDF(색 그대로), Word, 엑셀, 글자 복사 |
| 설정 | 요율 기간 · 안전재고(개월분)·리드타임·MOQ·발주단위 기본값 · 장기·불용·변동 기준 · 차 3개월 생산계획(직접·붙여 넣기) · **자재별 MOQ·리드타임·안전재고·발주단위**(직접·엑셀 붙여 넣기) · AI 연결 · JSON 백업 |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음)
- 일부러 깨뜨려 테스트가 잡는지: `node scripts/break-check.mjs`
- 브라우저 점검(선택): `PLAYWRIGHT_CORE=/경로/node_modules/playwright-core node scripts/check-browser.mjs`
- 샘플 파일 다시 만들기: `node scripts/make-samples.js` → `samples/수불_샘플_2026-10.xlsx`
- 기획서 Word 다시 만들기: `python3 scripts/make-docx.py` (python-docx 필요)

## 1단계 구현 범위

| 요청 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 차 3개월 생산대수 기반 예상 출고량 | 완료 | 대당 요율(대수 가중, 기간 선택) × 생산계획 대수. 계획이 없는 달은 직전 평균 대수 |
| 월별 기초재고 감안 부족 강재량 | 완료 | 현재고 + 발주잔량에서 굴린 월말 재고, 안전재고 대비 부족량·결품량, 강종별 합 |
| 발주 우선순위 색 구분 | 완료 | 빨강·주황·노랑·초록 + 발주 마감월. 색 기준은 화면·기획서에 적음 |
| MOQ·Lead time 감안 발주 시점 | 완료 | 자재별 MOQ·리드타임·발주단위·안전재고. 실제 값은 확인 대기(기획서 10장 ③④) |
| 장기·불용재 사전 방지 지표 | 완료(임시 기준) | 재고 개월수·무출고·출고 감소·MOQ 과다. 불용 정의는 확인 대기(10장 ⑤) |
| lot 단위 절단 영향 | 일부 | 월별 출고 변동으로 「들쭉날쭉」 자재를 찾아 안전재고 상향을 권함. 절단 계획 직접 반영은 2단계 |
| 발주서 양식·ERP 연동·공유 | 2단계 | 지금은 엑셀 내보내기 + 브라우저 저장 + JSON 백업 |
