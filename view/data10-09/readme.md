# data10-09 · 품질보증팀 업무 경험 수집 및 AI 기반 디지털 업무 자료화

기존 업무자료(절차서 · 지침서 · 체크리스트 · 기록 양식 · 시스템 입력 항목 · 업무 순서 자료 · 캡처)와 담당자의 설명 · 경험(암묵지)을 모아, AI 로 **업무 프로세스 흐름도와 단계별 업무 방법서 초안**을 만드는 브라우저 도구. 단계마다 근거(문서 / 담당자 답변 / AI 추정)와 「담당자 확인」을 보이고, 업무 방법서 · 단계표 · 인수인계 체크리스트 · 1장 요약으로 냅니다.

> 과제는 패들릿으로 접수했습니다. 실제 업무 자료는 아직 받지 않았고(기획서 「방향 수정」 확인 목록), 샘플 「수입검사 부적합품 처리」의 절차서 · 체크리스트 · 시스템 입력 항목 · 화면 그림 · 담당자 답변 · AI 답은 일반적인 제조업 품질보증 업무로 새로 지은 **가상 값**입니다(문서번호 · 메뉴 · 수치 포함). 소속 회사명은 리포에 두지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-09/**

처음 열면 「① 업무 · 자료 넣기」 화면입니다. **「샘플로 해 보기」** 를 누르면 가상 「수입검사 부적합품 처리」(자료 3 · 화면 그림 1 · 답 11/13 · 말로 한 설명 1 · AI 초안 v1)가 들어갑니다. ③ 화면의 「샘플 AI 답 넣기」로 AI 없이도 답 읽기 → 새 판 저장까지 해 볼 수 있습니다.
파일 · 사진 · 답변은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다. AI 에는 사람이 복사한 프롬프트만 들어가고, 설정에서 사내 OpenAI 호환 서버를 적은 경우에만 「자동 보내기」가 됩니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀 · docx 읽기는 `vendor/` 의 SheetJS — docx 는 그 안의 zip 읽개로 `word/document.xml` 만 풂).

| 화면 | 하는 일 |
|---|---|
| ① 업무 · 자료 넣기 | 업무 만들기(1단계 업무 목록 52가지에서 고르기 가능) · 자료 붙여 넣기 · txt(UTF-8/EUC-KR) · docx(문단 · 표) · xlsx(시트마다) — PDF · 한글은 글자 복사 안내 · 자료 종류 짐작 · 고치기 · 1단계 흐름도를 「업무 순서 자료」로 · 캡처 · 사진(큰 사진은 1600px 로 줄여 IndexedDB, AI 에는 설명만) · 자료 번호 M1 · P1 |
| ② 담당자 인터뷰 | 기본 질문지 13개(순서 · 판단 기준 · 수치 · 예외 · 실수 · 주의 · 양식 · 시스템 화면 · 소요시간 · 넘기는 곳) · **AI 로 질문 뽑기**(자료와 실제가 다른 곳, 겹치는 질문 뺌) · 질문마다 답 저장(여러 번에 나눠) · 답 없는 것만 보기 · 질문지 인쇄 · **말로 한 설명 붙여 넣기**(T1) |
| ③ 초안 만들기 | 자료 + 답변 + 설명 + 사진 설명 + 「못 받은 질문」을 묶은 프롬프트(요청형, 「지어내지 말고 더 확인할 것으로」) → 답(JSON) 붙여 넣기 → 검사(``` · 끝 쉼표 · 끊김 · 없는 근거 id · 흐름 고리) → **흐름도**(1단계 그리기 재사용, 판단은 마름모) + **단계별 업무 방법서**(누가 · 입력 · 방법 · 기준 · 예외 · 주의 · 양식/시스템 · 시간) · 단계마다 근거 **문서 / 담당자 / 둘 다 / AI 추정** · 칸 단위 「AI 추정」 · 근거 사진 · **담당자 확인** · 단계 고치기(새 판) · 판 기록 · 「더 확인할 것」→ 인터뷰 질문 |
| ④ 내보내기 | Word 업무 방법서(흐름도 그림 · 근거 사진 포함) · Excel 단계표(단계표 · 근거 자료 · 용어 · 더 확인할 것 · 체크리스트 5시트) · 인수인계 체크리스트(인쇄 · Excel) · 1장 요약(인쇄 · Word) · 흐름도 SVG · PNG · 1단계 흐름도 · 신입 교육으로 보내기 |
| 기존 도구 (1단계) | 업무 목록 가져오기 · 핵심 업무 선정 · 문서 맵 · 업무 흐름도 · 신입 교육 — 처음 방향의 기능 그대로 |
| 설정 | 계산 기준 · AI 연결(OpenAI 호환 주소 · 모델 · 본인 키, 기억은 선택) · JSON 백업(사진 포함) |

- 로직 테스트: `node test/capture.test.mjs`(업무 자료화 20개) · `node test/logic.test.mjs`(1단계 33개) — 의존성 없음
- **판 올리기(고칠 때마다)**: `node scripts/bump-version.mjs 2026-10-28.1` — index.html 의 모든 js·css `?v=` · logic.js · capture.js · app.js 를 같은 값으로. 섞이면 화면이 「새 판이 나왔습니다 — 새로고침(Ctrl+F5)」로 멈춥니다. `--check` 로 같은지만 봅니다
- 브라우저 점검(선택): `PLAYWRIGHT_CORE=<playwright-core 경로> [CHROME_PATH=<크롬 실행 파일>] node scripts/check-capture.mjs` — 옛 판 자료 옮기기 · 망가진 자료 · 샘플 한 바퀴 · 파일 넣기 · 흐름도 글자 실측 · 내보내기 · 백업 · 4가지 폭 가로 넘침 · JS 오류. 1단계 화면은 `scripts/check-browser.mjs`
- 샘플 엑셀 다시 만들기: `node scripts/make-samples.js` · 기획서 Word: `python3 scripts/make-docx.py`
