# data10-09 · 품질 업무 프로세스 문서 작성 및 신입사원 교육 자료 제작

품질 업무 목록(52가지 엑셀)에서 핵심 업무 10~15개를 고르고, 문서 목록 · 문서 맵 · 연계 · 누락 체크리스트, 직책별 업무 흐름도(단계 표 → 자동 그림), 신입사원 교육 커리큘럼과 업무별 「교육 한 장」을 만드는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 신나희 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-10-20) — https://aebonlee.github.io/data10-09/ |
| 다음 개발 | 2단계 — 실제 업무 엑셀 · 문서 목록 · 근거 절차서로 핵심 업무 하나의 「흐름도 + 연계 문서 + 교육 한 장」 견본 다듬기, 지금 쓰는 교육자료 양식 반영, 절차서 근거 질의(RAG), 팀 공유 |

> 과제는 패들릿으로 접수했습니다. 실제 업무 엑셀 · 문서는 아직 받지 않았고(기획서 10장 ①), 샘플은 일반적인 제조업 품질 업무로 새로 지은 **가상 값**입니다(문서번호 · 개정일 포함, 특정 규격의 조항 번호는 쓰지 않음). 소속 회사명은 공개 리포에 두지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-09/**

처음 열면 「가져오기」 화면입니다. **「샘플로 시작」** 을 누르면 가상 업무 52개 · 문서 24개와 흐름도 · 교육 한 장 3개(수입검사 실시 · 부적합품 처리 · 고객 클레임 대응)가 들어가고 ① 핵심 업무 선정 화면으로 넘어갑니다.
샘플에는 체크리스트가 찾아야 할 것을 일부러 심어 두었습니다 — 업무 목록에만 있는 「포장 사양서」, 흐름도에만 나오는 「거래명세서」「작업표준서」, 어떤 업무에도 연결되지 않은 「신뢰성 시험 지침」, 개정한 지 3년이 넘은 문서 8개, 버전 · 담당이 빈 문서.
실제로 쓸 때는 업무 목록 엑셀(업무명 · 주기 · 소요 시간 · 직책, 있으면 구분 · 관련 문서)을 넣어 주세요. 열 이름이 조금 달라도 찾고, 못 찾은 열은 화면에서 골라 연결합니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).

| 화면 | 하는 일 |
|---|---|
| 가져오기 | 업무 목록 · 문서 목록 엑셀 · 제목 줄 아래 머리행 자동 인식 · 열 이름 별칭(「업무 항목」「빈도」「공수」「담당자」 …) · 열 연결 확인/수정 · 병합 셀 「구분」 이어 쓰기 · 같은 업무명 건너뛰기 · 주기 · 소요 시간 글 점검 · 다시 가져와도 핵심 선택 · 흐름도 · 교육 자료 유지 |
| ① 핵심 업무 선정 | 점수(0~100) = 빈도 × 소요 시간(연간 시간, 로그) · 신입 관련성(1~5) · 고객 영향(1~5)의 가중 평균 — 가중치 조정 · 상위 N개 추천 · 직접 고르기 · 순서 바꾸기 · 난이도 · 10~15개 범위 점검 · 엑셀 |
| ② 문서 맵 | **문서 맵**(핵심 업무별 정형 · 비정형 · 형식 줄) · **업무 × 문서 연결표**(칸을 누르면 잇기 · 끊기, ○ 흐름도에만 나옴) · **문서 목록**(번호 · 종류 · 버전 · 개정일 · 담당, 직접 넣기 · 고치기) · **연계 · 누락 체크리스트**(문서 없는 핵심 업무 · 정형 근거 없음 · 고아 문서 · 오래된 버전 · 목록에 없는 문서 이름, 바로 고치는 단추 · 확인 표시 · 엑셀 · 인쇄) |
| ③ 업무 흐름도 | 단계 표(단계명 · 담당 직책 · 입력/산출 문서 · 판단 질문 · 예/아니오 → 단계) → **직책별 칸(swimlane) SVG 흐름도** 자동 그리기 · 단계 넣기/빼기/옮기기(번호 따라 바뀜) · 흐름 점검(갈 곳 없는 판단 · 닿지 않는 단계 · 끝없는 고리) · 글자 겹침 점검 · SVG · PNG · 인쇄 · 단계 표 엑셀 · **AI 로 절차서 문단 → 단계 표**(복사 · 붙여 넣기, 선택: 설정한 AI 서버로 자동 보내기) |
| ④ 신입 교육 | 주차별 커리큘럼(난이도 쉬움 → 어려움, 같은 난이도는 핵심 업무 순서, 1주차 문서 체계 오리엔테이션) · 업무별 **교육 한 장**(목적 · 흐름도 · 핵심 포인트 · 자주 하는 실수 · 함께 볼 문서 · 확인 퀴즈 3문항) — 흐름도 사실로 초안 · 퀴즈 자동 만들기 · 인쇄/PDF · Word · AI 초안(반자동) |
| 설정 | 수시 업무의 1년 횟수 · 근무일 · 1일 시간, 핵심 업무 범위, 오래된 버전 기준(개월), 교육 기간(주), AI 연결(OpenAI 호환 주소 · 모델 · 본인 키, 기억은 선택), JSON 백업 |

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 33개)
- **판 올리기(고칠 때마다)**: `node scripts/bump-version.mjs 2026-10-28.1` — index.html 의 모든 js·css `?v=` · logic.js · app.js 를 같은 값으로. 브라우저가 옛 파일과 새 파일을 섞어 쓰지 않게 하고, 섞이면 화면이 「새 판이 나왔습니다 — 새로고침(Ctrl+F5)」로 멈춥니다. `--check` 로 같은지만 봅니다(로직 테스트도 봄)
- 샘플 파일 다시 만들기: `node scripts/make-samples.js` → `samples/` 업무 목록 · 문서 목록 xlsx (다시 읽어 원본과 같은지 확인)
- 브라우저 점검(선택): `PLAYWRIGHT_CORE=<playwright-core 경로> node scripts/check-browser.mjs` — 주요 흐름 + 흐름도 글자 실측(getBBox) + 6가지 폭 가로 넘침
- 기획서 Word 다시 만들기: `python3 scripts/make-docx.py` (python-docx 필요)

## 1단계 구현 범위

| 요청 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 문서 목록 및 맵 | 완료 | 정형 · 비정형 · 형식 · 버전 · 개정일 · 담당, 업무별 문서 맵, 업무 × 문서 연결표. 실제 문서 목록을 받으면 엑셀로 넣거나 직접 입력 |
| 문서 간 연계 · 누락 확인 체크리스트 (핵심 업무 우선) | 완료(규칙) | 핵심 업무 → 문서 → 업무 목록 순. 오래된 버전 기준은 설정(기본 36개월) |
| 업무 흐름도 (핵심 업무 10~15가지) | 완료(그리기 도구) + 견본 3개 | 단계 표에서 직책별 흐름도를 그림. 실제 흐름은 근거 절차서를 받아 채움(10장 ③) |
| 핵심 업무 고르기 | 완료(점수 + 직접 선택) | 이미 정한 기준이 있으면 그 기준을 먼저(10장 ②) |
| 신입사원 교육 커리큘럼 · 자료 | 완료(기본 양식) | 주차 배치 · 교육 한 장 · 퀴즈. 지금 쓰는 교육자료 양식을 받으면 모양을 맞춤(10장 ④⑤) |
| 팀 공유 | 2단계 | 지금은 브라우저 저장 + JSON 백업 |
