# data10-01 · 굴착기 카운터웨이트 프레스 예지보전

프레스 로그(타수·가동 시간·전류·전압·온도·진동)를 가져와 2초 센서 값의 ±3σ 실시간 관리도·온도 3구간(예열·안정 생산·위험) 관리선, 설비 실시간 연결(시뮬레이터·HTTP·WebSocket), 고장 전 이탈 리드타임, 금형별 타수 집계·교체 예정일, 오버홀 알림, 통계 기준 이상 감지, 월별 프레스 종류별 타수 보고서를 만드는 브라우저 도구

> 1단계는 패들릿 게시물·댓글만으로, 2차는 수강생이 보낸 로그 샘플(2초 간격 모의 데이터)과 「±3σ 관리선」 요청으로, 3차는 수강생 답(10-27 — 기준 구간 = 전체 구간, 실제 대신 가상 더미 데이터, 실시간 = 설비에서 바로)과 온도 3구간 요청으로 만들었습니다. 리포의 샘플·가상 데이터는 모두 새로 만든 **가상 값**입니다(수강생 파일은 두지 않음).

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-01/**

**3차 — 가상 고장 데이터 · 실시간 연결 · 온도 3구간**:
- 「데이터 가져오기 → 가상 고장 데이터(3대 × 5일 + 이력)」 — 프레스 P1~P3 × 10/19~23 2초 로그 216,000행과 고장 3건·정비 3건·금형 교체 2건(모두 가상)을 넣고 「고장 전 이탈」 화면으로 갑니다. 고장 3건 모두 경보가 먼저 울렸고(리드타임 1.5~3.8시간), 관리선 기준을 「전체 구간」과 「고장 전 구간을 뺀 전체 구간」으로 나란히 견줍니다.
- 「실시간 연결」 — 내장 시뮬레이터(이 브라우저 안, 고장 징후 넣기), HTTP(S) 주소를 N초마다 받기(JSON·CSV, `{since}`), WebSocket. 상태·마지막 수신·지연·시간 틈을 보이고, 관리도가 밀려가는 창으로 다시 그려지며 경보가 바로 뜹니다. 넣은 주소로 받기 요청만 보냅니다.
- 내 PC 에서 설비 쪽 흉내: `node tools/relay.mjs` (의존성 없음) → 주소 `http://localhost:8787/api/rows?since={since}` 또는 `ws://localhost:8787/ws`. 같은 서버가 이 페이지도 줍니다(`http://localhost:8787/`). `--csv 2초로그.csv --speed 10` 이면 받은 로그를 다시 흘려보냅니다. 받는 형식 표본: `tools/sample-rows.json`·`tools/sample-rows.csv`. 설비에서 바로 받는 2단계 구성(PLC → 게이트웨이 → 중계 → 페이지)과 협력사 접속 보안은 기획서 12.4.
- 온도는 ±3σ 대신 「예열 · 안정 생산 · 위험」 3구간(경계는 데이터로 잡은 기본값, 프레스마다 바꿈), 구간별 시간·예열 시간·위험 경보. 관리선 기준 구간 기본값은 「데이터가 있는 전체 구간」.

**2차 — 2초 센서 로그**: 설비가 2초마다 보낸 로그 CSV(일자에 초까지)를 그대로 넣으면 「실시간 관리도」로 갑니다. 「2초 로그 샘플(4대 × 3일)」 버튼으로 먼저 둘러볼 수 있습니다 — P2 전류 상승(±3σ 이탈), P3 20분 정지·진동 튐, P4 금형 교체(금형 타수 0), P1 기록 끊김을 심어 두었습니다.

처음 열면 「데이터 가져오기」 화면입니다. **「샘플 90일로 시작」** 을 누르면 가상 로그 4개 파일(7·8·9월 엑셀, 10월 CSV)과 설비·금형 기준표가 들어가고 대시보드로 넘어갑니다. 일부러 심어 둔 세 가지가 바로 보입니다 — 금형 M-05 수명 임박(주의), P2 마지막 2주 전류·온도 상승(점검 필요), P4 오버홀 주기 지남(점검 필요).
실제로 쓸 때는 로그 엑셀·CSV 를 여러 개 한꺼번에 넣고, 설정에서 금형 수명 기준 타수와 오버홀 주기를 넣습니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).

**외부 망·협력사 접속** — 위 주소는 회사 밖 어디서나 열립니다. 실시간 값은 중계가 내놓는 곳에서만 오므로, 협력사가 밖에서 보려면 중계를 HTTPS·토큰으로 내놓아야 합니다(기획서 12.4). 그 밖의 데이터는 **각자의 브라우저에만** 저장하므로, 협력사가 같은 주소로 들어와도 서로의 데이터는 보이지 않습니다(각자 자기 로그를 넣어 씀, 백업 JSON·기준표 엑셀로 주고받기는 가능). 같은 데이터를 함께 보는 협력사 공유·로그인은 2단계(Supabase)에서 만듭니다.
