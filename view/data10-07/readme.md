협력사 공정불량을 화면에서 바로 등록하거나 엑셀 표를 붙여 넣어 불량유형 10종으로 분류하고, 불량유형 WORST 1·2·3 · 동일품번 2건 이상을 우선 개선 항목으로 개선 MASTER PLAN 초안을 만들어(Copilot 등으로 다듬기) 간트로 관리하고, 「불량목록」·「MASTER PLAN」 Excel 을 협력사와 주고받아 진행사항을 갱신하는 사내망 전용 브라우저 도구 — HTML 한 파일로 사내 PC 에서 씁니다

## HTML 파일 한 개로 쓰기 (사내 PC — 권장)

사내 보안망에서 GitHub 에 들어가기 어려워, 도구 전체를 **HTML 파일 한 개**로 만들어 둡니다.

- 받기: https://aebonlee.github.io/data10-07/dist/data10-07_협력사공정불량_개선관리.html (도구의 「설정 → HTML 파일로 받기」 또는 화면 아래 줄 링크)
- 쓰기: 받은 파일을 사내 PC 의 폴더에 저장 → **더블클릭**(Edge·Chrome). 설치·인터넷이 필요 없고 외부 주소를 부르지 않습니다.
- 데이터: 그 PC 의 그 브라우저 안(localStorage)에만 저장됩니다. PC 를 바꿀 때는 「백업 · 복원」의 JSON 을 받아 새 PC 에서 되살립니다.
- 새 판으로 바꾸기: 새 파일을 받아 **같은 이름 · 같은 폴더**에 덮어쓰고 같은 브라우저로 엽니다(데이터가 이어짐). 바꾸기 전에 JSON 백업을 받아 두세요. 화면 아래 줄에 지금 판(예: 2026-10-27.2)이 보입니다.
- 만들기(개발): `node scripts/build-single.mjs` → `dist/…html`. `--check` 는 dist 가 지금 소스와 같은지만 봅니다. 판 올리기(`bump-version.mjs`)가 같이 다시 만듭니다.

## 실행 방법

**온라인 시연: https://aebonlee.github.io/data10-07/** (가상 데이터로 흐름을 보는 용도)

### 사내망에 폴더째 두고 쓰기 (HTML 한 파일 대신)

1. 파일 묶음(ZIP)을 **aebon@dreamitbiz.com** 으로 문의해 받아 압축을 풉니다.
2. 폴더를 **통째로** 사내 공유 드라이브나 사내 웹서버(IIS·Apache·nginx 등의 정적 폴더)에 둡니다. `index.html`·`css/`·`js/`·`vendor/` 가 같은 자리에 있어야 합니다.
3. `index.html` 을 엽니다(공유 드라이브는 더블클릭, 웹서버는 그 주소). 설치·인터넷 연결이 필요 없습니다.
4. 데이터는 **각 PC 의 브라우저 안에만** 저장됩니다. 다른 사람과 나누거나 PC 를 바꿀 때는 「불량 등록 → 백업 · 복원」의 JSON(전부)·엑셀(불량 목록) 파일을 사내 공유 폴더로 주고받습니다. 브라우저 기록을 지우기 전에는 꼭 백업을 받아 두세요.
5. AI 는 API 키 없이 씁니다 — MASTER PLAN 의 「프롬프트 복사」 → Copilot(또는 임시 채팅의 ChatGPT · Claude · Gemini)에 붙여 넣기 → 답 붙여 넣기. 「설정 → AI 연결 설정」은 사내 AI 서버가 있을 때만 씁니다.

처음 열면 대시보드입니다. **「불량 등록」** 에서 바로 적기 시작하거나, **「예시 데이터로 시작」** 으로 가상 151건(협력사 C 의 용접불량이 8~10월에 늘어나는 것, 같은 품번 반복, 어느 유형에도 맞지 않는 내용 3건을 일부러 심음)을 넣어 흐름을 먼저 볼 수 있습니다.
