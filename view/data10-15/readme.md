# data10-15 · 협력사 클레임 보상 합의서·인보이스 작성 자동화

협력사와 보상 합의를 마친 결과 엑셀을 올리면 협력사별로 묶어 금액을 검증하고, 회사가 쓰던 합의서·인보이스 엑셀 양식의 `{{키}}` 칸을 채워 서식 그대로의 엑셀과 인쇄용 PDF 를 만드는 브라우저 도구

| 항목 | 내용 |
|---|---|
| 제출자 | 안민준 |
| 과정 | 현장 데이터 디지털화 전문가과정 2차수 (2026) |
| 진행 단계 | 1단계 개발 완료 (2026-10-21) — https://aebonlee.github.io/data10-15/ |
| 다음 개발 | 2단계 — 실제 합의 결과·회사 양식으로 열 연결과 키 칸 맞추기, 양식 그대로의 PDF 자동 변환, 결재·메일 발송 |

> 과제는 패들릿으로 접수했습니다. 실제 합의 결과·양식은 아직 받지 않았고(기획서 10장 ①②), 샘플은 「A정밀(가상)」처럼 지어낸 협력사 6곳과 지어낸 클레임 번호·품번·금액으로 만든 **가상 값**입니다. 기본 양식 2종도 가상입니다. 소속 회사명은 공개 리포에 두지 않습니다.

## 실행 방법

**온라인에서 바로 보기: https://aebonlee.github.io/data10-15/**

처음 열면 「데이터 가져오기」 화면입니다. **「샘플로 시작」** 을 누르면 가상 합의 결과 22행(협력사 6곳, 원화 5 · 달러 1)이 들어가고 협력사별 합의 화면으로 넘어갑니다.
샘플에는 검증할 거리를 심어 두어, 확인 필요 2행 · 주의 5행이 보이고 「확인 필요」가 있는 2곳은 처음에 문서 만들기 선택이 꺼져 있습니다.
실제로 쓸 때는 합의 결과 엑셀을 넣어 주세요. 열 이름이 조금 달라도 찾고, 못 찾은 열은 화면에서 골라 연결합니다. 파일은 서버로 보내지 않고 이 브라우저 안에서만 읽고 저장합니다.

내 PC 에서 열려면 `index.html` 을 더블클릭하거나, 폴더에서 `python3 -m http.server 8000` 후 `http://localhost:8000` 을 엽니다. 외부 CDN 을 부르지 않습니다(엑셀은 `vendor/` 의 SheetJS).

| 화면 | 하는 일 |
|---|---|
| 데이터 가져오기 | 합의 결과 엑셀 여러 개 · 제목 줄 아래 머리행 자동 인식 · 열 이름 별칭(「업체명」「거래처」「보상금액」「귀책률」 …) · 열 연결 확인/수정 · 합계 줄 건너뛰기 |
| ① 협력사별 합의 | 협력사(코드 우선)별 건수·청구합계·합의합계·부가세·총액·부담 비율, 검증 판정, 문서 만들 곳 고르기, 최근 발행 번호 |
| ② 클레임 명세·검증 | 행마다 합의금액(칸 우선, 비면 청구금액 × 부담 비율)과 검사 — 확인 필요(합의 > 청구 · 금액 없음 · 비율 범위 · 통화 섞임) / 주의(비율 계산과 다름 · 번호 겹침/없음 · 0원) · 검토표 엑셀 |
| ③ 문서 만들기 | 발행일, 합의서·인보이스 고르기, 문서 번호 미리 보기(재발행/새 번호), **엑셀 내려받기 — 여러 개는 zip 한 파일** |
| ④ 인쇄 · PDF | 인쇄용 기본 양식(한 문서 한 쪽, 여러 협력사 한 번에) → 「PDF로 저장」, 올린 엑셀 양식 모양 미리 보기 |
| ⑤ 양식 템플릿 | 회사 양식에 `{{키}}` 를 적어 올리기, 키 칸·반복 줄 살펴보기, 모르는 키 알림, 기본 양식 내려받기, 키 목록 36개(복사) |
| ⑥ 발행 이력 | 확정한 문서 번호(종류·달마다 일련), 재발행 횟수, 대체됨·취소 표시, 엑셀 |
| 설정 | 발행처·부서·담당·연락처·입금 계좌, 기본 통화, 부가세(없음/10% 별도), 반올림·원 단위, 허용 차이, 지급 기한, 문서 번호 형식·접두, 합의 조건 문구, JSON 백업 |

### 회사 양식 쓰는 법(요약)

1. 지금 쓰는 합의서(인보이스) 엑셀 양식을 복사하고, 값 칸에 `{{협력사명}}` `{{문서번호}}` `{{총액}}` `{{총액_표기}}` 같은 키를 적습니다.
2. 클레임 목록 표는 첫 줄에만 `{{행.번호}}` `{{행.클레임번호}}` `{{행.합의금액}}` … 을 적습니다. 그 아래 빈 표 줄을 먼저 채우고, 모자라면 줄을 끼워 넣으며 합계 줄·병합·`=SUM()` 범위·인쇄 영역·그림 위치를 함께 내립니다.
3. ⑤ 양식 템플릿에서 올리면 서식(글꼴·테두리·색·병합·로고·직인 그림)은 그대로 두고 값만 채웁니다.

- 로직 테스트: `node test/logic.test.mjs` (의존성 없음, 31개)
- 브라우저 점검(선택): `PLAYWRIGHT_CORE=/경로/node_modules/playwright-core node scripts/check-browser.mjs`
- 샘플 합의 결과 다시 만들기: `node scripts/make-samples.js` → `samples/클레임_합의결과_샘플.xlsx`
- 기본 양식 다시 만들기: `python3 scripts/make-templates.py` (openpyxl 필요) → `samples/*_기본양식.xlsx` + `js/builtin-templates.js`
- 기획서 Word 다시 만들기: `python3 scripts/make-docx.py` (python-docx 필요)

## 1단계 구현 범위

| 요청 | 상태 | 1단계에서 한 것 / 남은 것 |
|---|---|---|
| 합의 Excel 업로드 → 협력사·클레임별 합의금액 자동 추출 | 완료 | 열 찾기·연결, 협력사별 묶기, 금액 검증. 실제 열은 확인 대기(기획서 10장 ①) |
| 기존 양식에 맞춰 문서 자동 작성 | 완료(양식 템플릿) | 양식에 `{{키}}` 를 적어 올리면 서식 그대로 채움, 반복 줄. 실제 양식은 확인 대기(10장 ②) |
| 합의서·인보이스 Excel 다운로드 | 완료 | 한 개 또는 zip 한 파일, 문서 번호 자동 채번·발행 이력 |
| 합의서·인보이스 PDF 다운로드 | 일부 | 인쇄용 기본 양식 → 브라우저 「PDF로 저장」. 회사 양식 그대로의 PDF 자동 변환은 2단계(10장 ⑤) |
| 수작업 입력 오류 최소화 | 완료 | 합의 > 청구 · 비율 계산과 다름 · 번호 겹침 등 검증, 한글 금액·합계 자동 |
| 결재·메일 발송·팀 공유 | 2단계 | 지금은 브라우저 저장 + JSON 백업 |
